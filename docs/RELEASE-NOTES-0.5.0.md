## dsh-whiteboard v0.5.0 — 首发：手写白板插件（含工具栏三栏布局与检查更新）

### 这是什么

DSH Desktop（DeepSeek Harness）的手写白板插件：左侧「手写白板」面板新建/继续编辑白板，
支持手写笔压感、单指平移、双指缩放、像素级橡皮与可调橡皮大小，白板保存在本机。

### 本版功能

- 历史白板列表（缩略图 / 标题 / 时间 / 笔画数，可重命名、删除）；
- 无限画布：单指拖动平移、双指缩放（以两指中点为中心）、滚轮缩放、抓手/空格拖动平移，视图随白板保存；
- 手写笔书写：铅笔 / 钢笔 / 毛笔 / 马克笔 / 橡皮（像素级擦除），压感、12 色、4 档粗细；
- 笔上橡皮键 / 侧键临时擦除；抬笔后手指无需重按即可接着平移（兼容 Windows 笔悬停防误触）；
- 橡皮擦大小拖动调整：6–400 世界像素，滑块 + `[` / `]` 微调 + 画布光标圆圈预览；
- 工具栏三栏：左工具（3×2 大按钮）、中颜色/粗细/橡皮、右操作（撤销·重做 ｜ 网格 ｜ 删除 ｜ 导出；缩放 + 适配）；
- 自动保存、导出 PNG、撤销/重做/清空；
- **检查更新**：自动静默检查 + 手动检查 GitHub Releases，只提示、不自动安装；网络失败时静默；
- **隐私**：白板数据只存本机、无遥测；联网仅检查更新（详见 PRIVACY.md）。

### 安装

下载 `dsh-whiteboard-0.5.0.tgz`，按 `INSTALL.md` 解压到
`%USERPROFILE%\.dsh\profiles\desktop\node_modules\`，在 profile `package.json` 的
`dependencies` 与 `dsh.profile.bundles` 中登记 `dsh-whiteboard`，然后重启 DSH Desktop。

### 兼容性

在 DSH Desktop 2.0.17（dsh 0.2.0-rc.2）上实测；依赖宿主提供侧栏/主面板 slot 与本地 Web 服务。

### 注意

- 大橡皮上限 400 需要宿主重启加载新版存储上限；未重启时界面自动按旧上限 156 兜底，不会保存出问题；
- Windows 下笔仍悬停屏幕上方时系统会暂时禁用触控（抬笔后手指延迟约 1 秒），这是系统的笔悬停防误触，把笔移开屏幕即可。
